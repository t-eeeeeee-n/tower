      配色
      Git Bash（mintty）のテーマを読み込みます。~/.mintty/themes にファイルを置くと、次の起動から選べます。

      通知

      表示中のセッションを見ているときは知らせません。サイドバーとタイトルの入力待ちの表示はオフにしても残ります。

      履歴

      ターミナルのスクロール履歴は、このあと開くセッションから変わります（開いているセッションは今のまま）。一覧でさかのぼれる行数は、スクロール履歴の行数までです。
